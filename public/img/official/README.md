# Logos oficiales Softura

Coloca aquí los archivos exportados de la presentación corporativa (PNG/SVG con fondo transparente).

## Estructura recomendada

```
official/
  clientes/          → Logos de clientes (ya usados en Conócenos)
  tech/              → Logos de tecnologías (nombre-slug.png, ej. react.png)
  cloud/             → AWS, azure.png, google-cloud.png, oracle.png
  lms/               → moodle.png, chamilo.png
  certificaciones/   → cmmi.png, moprosoft.png, maagticsi.png, psp.png, scrum.png
  ies/               → upt.png, utt.png, jcf.png
  servicios/         → Ilustraciones de slides (opcional)
```
